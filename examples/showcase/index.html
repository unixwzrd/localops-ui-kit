What runs here?

Everything runs in your browser. Preferences reset on reload. Task and path actions change example data, not your machine. The copy control requests browser clipboard permission on HTTPS or localhost. Use your browser's Back command to return from focused demos.

WebUI is primary. Textual and Rich support shared semantic definitions with documented fallbacks; the direct editor, content panel and results reader do not claim terminal parity. See the widget reference for APIs, adapter responsibilities and limitations.
